# 작업 기록 (SESSION-LOG)

## 2027 ROBOFEST World Championship 국내예선대회 누리집

**이 문서는 "무슨 일이 있었는지"를 시간 순서로 적어 둔 기록입니다.**

Claude Code 는 대화를 기억하지 못합니다. 새 창을 열면 지난번에 무엇을 왜
했는지 하나도 모르는 상태에서 시작합니다. 그래서 매번 같은 설명을 다시
해야 하고, 이미 한 번 버린 방법을 또 제안하기도 합니다.

이 문서가 그 빈자리를 메웁니다. **세션을 시작할 때 맨 위 2~3개만 읽으면**
직전에 무슨 일이 있었는지 따라잡을 수 있습니다.

## 2026-08-14 (2) — 카드 등장 효과가 안 돌던 원인을 찾아 고침

**한 일**

- **원인**: 숨기는 클래스(`row-reveal`)와 보이게 하는 클래스(`is-in`)가
  **한 번의 스타일 계산 안에서** 붙어, 브라우저가 `opacity: 0` 을 한 번도
  계산하지 않았습니다. 시작값이 없으니 전환이 생략되고 카드는 그냥
  처음부터 보입니다. 섹션이 **이미 화면 안에 있는 채로** 스크립트가 실행될
  때 일어납니다 — 그 자리에서 새로고침하면 스크롤이 복원되므로 늘 그렇게
  됩니다. 실측: 195ms 숨김 → 206ms 보임, opacity 는 1.00 에서 한 번도
  내려가지 않음.
- **고침 ①** `src/components/RowReveal.tsx` — 숨긴 직후 `void el.offsetHeight`
  로 스타일을 강제로 한 번 계산시켜 '숨김'을 확정합니다.
- **고침 ②** `src/app/globals.css` — `transition` 을 `.row-reveal` 에서
  **`.row-reveal.is-in` 쪽으로 옮겼습니다.** 예전에는 숨김 상태에도 전환이
  걸려 있어, 클래스가 붙는 순간 보이던 카드가 0.4초에 걸쳐 **사라지는**
  모습이 그대로 보였습니다. 이제 숨김은 즉시, 나타남만 부드럽습니다.
- **고침 ③** 시작 기준을 `rootMargin -15%` 에서 **`threshold 0.15`** 로
  바꿨습니다(담당자 지정). 목록이 화면보다 훨씬 길어 15% 에 닿을 수 없는
  경우를 위한 안전장치도 함께 넣었습니다.
- 실제 크롬으로 재현 → 수정 → 재확인까지 했습니다. `tsc`·`lint`·`build` 통과.

**정한 것**

- ★ **`void el.offsetHeight` 한 줄을 지우지 마세요.** 이 줄이 없으면 효과가
  통째로 안 돕니다. 이유는 그 자리 주석에 적어 두었습니다.
- ★ **숨김 상태(`.row-reveal > *`)에 `transition` 을 넣지 마세요.**
  넣는 순간 '보이던 카드가 서서히 사라지는' 모습이 생깁니다.
- ★ **`requestAnimationFrame` 으로 미루는 방식은 쓰지 않습니다.** 다른 탭에
  가려져 있으면 rAF 가 멈춰 카드가 영영 안 보일 수 있습니다.

**남은 일**

- 없음.
